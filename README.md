# Rent a Car — Dark & Light Theme

A React Native application built with Expo and TypeScript for browsing rental cars, with support for light and dark themes.

## Features

- Light and dark theme support
- Car brands and models
- Car information and pricing
- Theme selection in settings

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the application

```bash
npx expo start
```

Scan the QR code using Expo Go, or open the app in an available simulator.

## Project Structure

The application source code is located in the `src` directory.
